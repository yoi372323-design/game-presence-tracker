📖 セットアップガイド

📝 ステップ 1: リポジトリのクローン

GitHub からプロジェクトをクローンします：

git clone https://github.com/yoi372323-design/game-presence-tracker.git
cd game-presence-tracker

🐍 ステップ 2: 仮想環境の作成

Python の仮想環境を作成して有効化します：

python -m venv venv
# Windows
venv\Scripts\activate
# Mac/Linux
source venv/bin/activate

📦 ステップ 3: 依存パッケージのインストール

pip install -r requirements.txt

⚙️ ステップ 4: 環境変数の設定

`.env` ファイルを作成して以下を設定します：

DISCORD_TOKEN=your_discord_bot_token_here
UPDATE_INTERVAL=30

🔑 ステップ 5: Discord Bot Token の取得

  1. Discord Developer Portal にアクセス
  2. 「New Application」をクリック
  3. アプリケーション名を入力
  4. 左側の「Bot」を選択
  5. 「Add Bot」をクリック
  6. 「TOKEN」をコピーして `.env` に貼り付け

🚀 ステップ 6: ボットの起動

python main.py

🎮 ステップ 7: Roblox User ID の入力

起動時に以下のプロンプトが表示されます：

🎮 あなたのRoblox User IDを入力してください:

あなたのRoblox User IDを入力してください。IDは以下で取得できます：

  1. Roblox にログイン
  2. プロフィールを開く
  3. URLから User ID を取得
    https://www.roblox.com/users/123456789/profile → 123456789

✅ 完了！

これでRobloxのゲーム情報がDiscordに表示されるようになります！
